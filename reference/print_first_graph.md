# Print multiple graphs across chunks

`print_first_graph` prints the first graph and returns the remaining in
a list `print_rest_of_graphs` prints the rest

## Usage

``` r
print_first_graph(graph_list)

print_rest_of_graphs(graph_list)
```

## Arguments

- graph_list:

  List of graphs to print

## Value

`print_first_graph` invisibly returns list of graphs with first dropped
