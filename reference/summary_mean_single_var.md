# Summary table of means for a single variable

Summary table of means for a single variable

## Usage

``` r
summary_mean_single_var(
  data,
  var,
  genders = c("Boys", "Girls"),
  classes = "All",
  .gender_split = TRUE
)
```

## Arguments

- data:

  Valid input data

- var:

  Variable to calculate mean of

- genders:

  List of genders to split by

- classes:

  List of classes to split by

- .gender_split:

  `TRUE`/`FALSE` - split by gender when sufficient numbers of responses

## Value

A summary table of means of a single variable
