# Full summary counts across all categories

Full summary counts across all categories

## Usage

``` r
create_full_summary(data, var, levels, genders, classes, .gender_split = FALSE)
```

## Arguments

- data:

  Valid input data

- var:

  Variable to calculate by

- levels:

  Character vector of ordered levels

- genders:

  List of genders to split by

- classes:

  List of classes to split by

- .gender_split:

  Gender split - passed from params

## Value

A dataframe of counted variables
