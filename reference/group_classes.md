# Create a vector of nicely named, class groupings

Create a vector of nicely named, class groupings

## Usage

``` r
group_classes(classes, groupings)
```

## Arguments

- classes:

  character vector of classes

- groupings:

  list of groups of classes, e.g. list(c("S1", "S2", "S3"), c("S4",
  "S5", "S6"))

## Value

A character vector of class groupings
