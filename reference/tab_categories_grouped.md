# Table of grouped classes by gender counts

Table of grouped classes by gender counts

## Usage

``` r
tab_categories_grouped(data, inc_gender, class_groupings)
```

## Arguments

- data:

  Valid school input data (with columns `gender` and `class`)

- inc_gender:

  List of genders to include in table

- class_groupings:

  List of groups of classes to include in table

## Value

A flextable giving gender by grouped class counts
