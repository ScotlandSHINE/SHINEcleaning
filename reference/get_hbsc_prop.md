# Get the HBSC Scotland proportion by gender for provided response

Get the HBSC Scotland proportion by gender for provided response

## Usage

``` r
get_hbsc_prop(classes, success, var = NULL)
```

## Arguments

- classes:

  classes to include

- success:

  responses to include, can provide multiple

- var:

  (Optional) variable to include

## Value

A tibble of proportion by gender
