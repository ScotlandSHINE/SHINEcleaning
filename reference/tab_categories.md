# Table of class by gender counts

Table of class by gender counts

## Usage

``` r
tab_categories(data, inc_gender, inc_classes)
```

## Arguments

- data:

  Valid school input data (with columns `gender` and `class`)

- inc_gender:

  List of genders to include in table

- inc_classes:

  List of classes to include in table

## Value

A flextable giving gender by class counts
